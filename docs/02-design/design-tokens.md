# DSH-Bridge｜设计令牌

将实际 token 同步到代码设计系统；本表是语义和验收的来源。禁止同一语义组件自行硬编码不同视觉值。

## 布局与间距

| Token | 默认值 | 用途 |
| --- | ---: | --- |
| `space-1` | 4px | 紧凑内部间距 |
| `space-2` | 8px | 基础间距 |
| `space-3` | 16px | 组件间距 |
| `space-4` | 24px | 区块内间距 |
| `space-5` | 32px | 区块间距 |
| `space-6` | 48px | 页面大间距 |
| `space-7` | 64px | 页面分区 |

栅格：桌面 12 列，平板 8 列，移动 4 列（按项目实际证据修改）。同语义元素共享边缘、基线、控件高度；同级卡片才等宽/等高/等距。

## 字体等级

| Token | 字号/行高 | 字重 | 用途 |
| --- | --- | ---: | --- |
| `display` | 40/48 | 700 | 强聚焦标题 |
| `h1` | 32/40 | 700 | 页面标题 |
| `h2` | 24/32 | 600 | 主分区标题 |
| `h3` | 20/28 | 600 | 次分区标题 |
| `body` | 16/24 | 400 | 正文 |
| `label` | 14/20 | 500 | 标签/控件 |
| `caption` | 12/16 | 400 | 辅助信息 |

仅使用 400/500/600/700 四档字重，除非品牌字体有明确例外。补充实际字体、颜色、圆角、阴影、边框、层级和断点 token。
