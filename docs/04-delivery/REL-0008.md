# REL-0008｜DSH-Bridge v0.0.12 发布记录（审计修复 v0.0.11 + AGENTS.md 路由规则）

## 变更集合

- **v0.0.11（红队审计修复）**：审计运行 `rt-20261119-133100-qs0t`（strike 档）的 120 条发现全部处理
  （P1 × 5 / P2 × 51 / P3 × 64，1 条 P3 保留为后续），逐条台账与回归证据见
  `docs/03-quality/audit-fix-ledger-2026-11-19.md`。要点：
  - 写 `.cs` 即执行的两条路径封死（`script.apply_edits`/`asset.create` 归入授权与审计 fail-closed）；
  - CLI 与插件共用同一授权管线（`Bridge.call`），硬拒绝在 CLI 侧真实生效；
  - 危险能力 16 → **17**（`unity.code.execute` 默认需显式授权），双侧清单双向一致性测试；
  - 模块分层门禁 `check-module-boundaries`（40+ 模块依赖方向 + 真实循环依赖检出）；
  - 零依赖 lint 门禁（语法 + 7 条风格规则）、文档契约校验（行为动词 vs 源码形态）。
- **v0.0.12（新增功能）**：安装/激活时把「凡是涉及团结/Unity 等 DSH-Bridge 支持的软件，运行时操作
  优先走 bridge；没有实例在运行也可先 `bridge_preinstall` 预植入准备用户指定或工作区对应的实例」
  的路由规则幂等写入 DSH 全局指令文件 `$HOME/.dsh/AGENTS.md`（哨兵
  `<!-- dsh-bridge:begin -->` … `<!-- dsh-bridge:end -->` 之间整块替换，用户其余内容不动；
  哨兵单边缺失抛 `agents_rule_corrupt`）。正文含标准流程/状态分派/无实例路径/普通工具例外边界/
  授权与安全/故障应对六个小节，11 个 bridge 工具全部点到。
  - 新文件 `core/agents-rule.mjs`；新配置 `agentsRule`（默认开启）、`agentsRulePath`；
    环境变量 `DSH_BRIDGE_AGENTS_RULE=0` 强制关闭；失败只记 warn 不阻断插件激活。
  - 新增 FR-0016；测试 `tests/unit/agents-rule.test.mjs`（12 项）。
- 版本：两处 `package.json` `0.0.10` → `0.0.11` → **`0.0.12`**；探针 `PROBE_VERSION` 保持 `27`
  （探针模板在 0.0.11 波次有内容变更，由安装器的 sourceHash 比对兜底触发重装）。
- 兼容性说明：`unity.code.execute` 由默认放行改为默认拒绝（破坏性默认值变更，需 `allowDangerous`
  显式开启）；CLI 的 `--dangerous` 语义与插件 `requireAuth` 同源；其余工具输出契约不变。

## 验证与风险

- 测试/门禁证据：`npm run verify` exit 0——**490 项测试全绿**（v0.0.10 为 478 项）、探针 csc 编译 OK、
  文档一致性通过、OpenSpec 3/3；`npm run verify:arch` 通过（仅存 LOC WARNING，无 ERROR）。
- 发布检查：README 配置表与环境变量表与 `resolveConfig` 反向一致（门禁强制）；模块边界无违规、无循环。
- 已知风险：插件以 symlink 形式安装在 `~/.dsh/profiles/desktop/node_modules/@local/dsh-bridge`，
  **已运行的 DSH 进程仍持有旧 JS，需重启 DSH（或等待插件 HMR 重载）后新行为才生效**；
  重启后 AGENTS.md 规则块会在插件激活时自动同步（幂等）。
- Go / No-Go：Go，负责人 lead（2026-11-19 15:30 +08:00）。No-Go 条件（协议破坏、探针不可卸载、
  回归缺失、审计被禁用时执行面放行）均未出现。

## 回滚

- 代码回滚：`git revert` 本发布 tag（`v0.0.12`）；0.0.11 的审计修复与 0.0.12 的功能在同一提交序列，
  回滚到 `v0.0.10` tag 可一并撤销。
- AGENTS.md 回滚：删除哨兵块（`dsh-bridge:begin` … `dsh-bridge:end`）即可，插件随后不会重写
  （或设 `agentsRule: false` 永久关闭）。
- 探针回滚：`bridge_uninstall` 后从 `v0.0.10` tag 重新 `bridge_install`。
