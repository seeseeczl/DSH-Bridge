# REL-0007｜DSH-Bridge v0.0.10 发布记录（v27 能力补齐）

## 变更集合

- 能力面 77 → **116**（新增 39 项），探针 `PROBE_VERSION` 26 → **27**，两处 `package.json` = `0.0.10`。
- 探针从 9 个 partial 文件扩到 **15 个**：新增 Graphics / Physics / UiToolkit / InputPlay / EditorMeta / Docs 六个域文件，
  每个域一个 `TryXxx(string cap, args)` 分发器；`Execute` 末尾按序调用，返回 `null` 表示本域不认领。
- 新增 DSH 工具 `bridge_docs`（工具面 10 → **11**）：不依赖运行中的实例，直接检索本机 Unity/团结安装内的
  官方 ScriptReference（`source: "local-docs"`），返回页面签名/描述/示例。

  探针侧 `_reflectCapabilities` 与 `safety/policy.mjs` 的 `DEFAULT_DANGEROUS` 新增**双向一致性单测**。
- 测试基础设施：`tests/unity-probe/stubs/*.cs` 域级 stub 收集器、`tests/unity-probe/cases/*.mjs` 域级语义用例注入。
- 文档：新增 ARCH-0002 规格；CAP-0001 能力矩阵重写（116 项 + 三方对比更新）；DETAIL/README/USAGE 更新；
  新增 FR-0015 / TASK-0032 / REG-PARITY-001/002/003 / REG-DOCS-001 / REL-0007。

## 设计取舍

- **包类型走反射**：URP/HDRP 的 Volume/RendererFeature/PostProcess、Input System、UI Toolkit 的 PanelSettings 全部通过
  `Type.GetType(...)` + try-catch 访问；缺失返回 `capability_unavailable` 并附 hint，不引用第三方程序集。
- **离线 stub 只服务编译与语义测试**：`stubs/*.cs` 补的是探针直接引用的内置 API；URP 替身（Volume 等）只让反射链路
  在离线环境真实执行，不会进入任何真实工程（渲染模板只写探针 15 个文件）。
- **只烘探针没有公开 API**：`bake.light_probes` 实际触发 `Lightmapping.BakeAsync()`（全场景），`bake.reflection_probes`
  走 `RenderProbe()`；返回带 `hint` 说明真实语义，不假装"只烘 LightProbe"。
- **文档两条路径**：`bridge_docs`（DSH 侧、无需实例、离线）与 `unity.docs.*`（随实例版本）互补；
  `unity.reflect.signature` 读真实程序集，包含工程自定义类型。
- **输入只做 Play Mode**：编辑器窗口事件仍走既有 `unity.input.send`；Play Mode 注入依赖 `com.unity.inputsystem`，
  未装包返回 `capability_unavailable`，旧 Input Manager 下不伪造成功。

## 兼容性

- 探针版本变化触发 `probeOutdated`：需 `bridge_install` 重装。安装器会删除清单外旧文件（v26 的 9 个文件会被清理）。
- 能力面只增不减（原 77 项全部保留），DSH 工具面只增（`bridge_docs`）。
- 危险能力新增 3 项：默认关闭；已配置的 `allowDangerous` 不受影响。
- 行为增强（非破坏）：`unity.graphics.stats` 追加 `batches/drawCalls/triangles/vertices`，取不到时标记 `statsUnavailable`。
- 数据/架构迁移：无数据迁移；`.git/info/exclude` 与通道布局不变。

## 验证与风险

- 离线（最终门禁实测）：`npm test` **249/249**；`npm run check:probe` → `probe compiles: OK`；
  `node tests/unity-probe/capability-semantics.mjs` → exit 0（**261 条用例**、0 CLR 崩溃、`writesOutsideProject=false`）；
  `npm run check:docs` → 通过（回归路径 58 条、任务卡路径 4 条）；`openspec validate --specs` → 3/3；
  `check-openspec-state` → 通过（开放变更 0、已归档 2）。
- 域级语义（真实渲染 C# → csc → mono）：7 个域测试文件 + 既有语义/形态测试共 **90 条断言**全部通过
  （graphics 12 / physics 10 / uitk 9 / inputplay 7 / editormeta 38 / docs 8 / 既有 6）。
- 架构门禁：`project-architect --check-docs --check-fitness --check-kickoff --check-traceability --strict`
  在 FR-0015 相关项上全部清零；剩余 ERROR 为 FR-0014/BUG-0002 历史追溯行（非本次引入，已单独记录）。
  `core/docs-index.mjs` 超限已按 EXC-0002 拆分为 engines/html/index 三个模块并标记偿还完成。
- 真机：**本轮未做**（环境内没有运行中的目标工程）。所有新增能力标注为「v27 离线」；
  `scripts/verify-live-capabilities.mjs` 已加入 G01–G12 真机冒烟用例，待下次在目标工程执行。
- 已知限制（各域如实上报，未掩盖）：
  - 图形：Volume 参数结构随 URP 版本变化，取不到的字段省略/进 `ignored`；`pipeline.set` 依赖 2021.2+。
  - 物理：`PhysicMaterial`（2022.3）与 `PhysicsMaterial`（Unity 6）用反射双探测；Edit Mode 下力不推进，返回 `simulated:false`；
    `Joint` 继承 Component 无 `enabled` 属性（返回 `enabled:null` + `enabledKnown:false`）；`collision_matrix` 使用真实 API
    `Physics.IgnoreLayerCollision(int,int,bool)`（同时兼容个别版本的 `SetIgnoreLayerCollision`）。
  - UI Toolkit：Edit Mode 视觉树可能为空，返回 `{empty:true,hint}`；资产刷新时序导致 create 后立即 validate 可能拿到 null。
  - 输入：依赖 Input System 包；sequence 的进度状态不跨域重载（`sequence_lost`）。
  - 文档：部分安装器不装 Documentation → `docs_unavailable`；类型页（如 Rigidbody.html）官方 HTML 的签名块为空，
    此时 `signatures` 返回空数组而不是编造。
- 残余风险：动态程序集不可卸载（既有边界）；URP 版本差异需真机回归收敛；InputSystem 反射注入需真机验证。

## 回滚

- 触发条件：v0.0.10 在目标工程出现兼容性问题（例如旧探针未重装导致 `probeOutdated`，或 URP 反射在某版本抛错）。
- 步骤：回退插件到 v0.0.9；目标工程 `bridge_uninstall` 后重装 v0.0.9 探针（26）；能力面回到 77 项。
- 验证：`bridge_targets` 状态 ready；`npm test` 全绿；旧版能力抽查通过。
