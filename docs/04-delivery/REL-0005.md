# REL-0005｜DSH-Bridge v0.0.8 发布记录（探针多文件拆分，偿还 EXC-0001）

## 变更集合

- FR/CR/BUG/ADR：新增 ADR-0003（多文件 partial class 探针包），取代 ADR-0002 的单文件约束。偿还 EXC-0001（TASK-0031）。无新 FR；FR-0014 能力面不变。
- 版本/提交/PR：两处 `package.json` = `0.0.8`；探针 `PROBE_VERSION` 24 → **25**（安装形态变化：旧单文件探针需重装）。
- 变更内容：
  - 探针按域拆为 9 个 `.cs`（同一 `public static partial class`），主文件 826 LOC、最大文件 1512 LOC（此前单文件 5951 LOC）。
  - `probe.template.mjs` 支持多文件渲染；`sourceHash` 覆盖文件名+全部内容。
  - 安装器写多文件（package.json + 9 个 `.cs`），重复安装幂等；升级时旧单文件被同名主文件覆盖；卸载仍删整目录。
  - `check:probe`、能力语义测试、安装/端到端测试全部适配多源文件编译。
- 兼容性：
  - 能力清单（77 项）、工具面（10 个）、`instance.json` 协议、授权快照语义均不变。
  - 安装写文件数 2 → 10；`bridge_install` 的 `files` 返回条目数相应变化（消费方应遍历而非固定下标）。
  - `PROBE_VERSION` 变化会触发 `probeOutdated`，已装旧探针需重装升级。
- 数据/架构迁移：无数据迁移；探针文件布局变化由安装器自动处理。

## 验证与风险

- 测试/构建：`npm test` **141 项全绿**；`npm run check:probe`（多文件 csc 编译）通过；`npm run check:docs` 通过；`openspec validate --specs` 3/3。
- 真机验证（团结引擎 2022.3.62t7）：多文件探针预植入后引擎 0 编译错误，心跳 `probe 24 / 77 能力 / sourceHash e3d6fb24537c57f4`（拆分前后能力清单与行为一致）；旧 57 用例矩阵 **57/57 通过**。
- 已知风险：安装器多文件写入是逐个 `writeFile`（非原子事务）；中断可能留下部分文件，但下次安装会补齐（幂等）。测试运行（动态编译桥接）等既有能力行为不变。
- Go/No-Go：Go，负责人 lead，2026-11-19 00:10（+08:00）。

## 回滚

- 触发条件：多文件探针在目标工程编译失败，或安装/卸载出现残留。
- 步骤：① DSH 侧回退 v0.0.7；② 目标工程 `bridge_uninstall`（删整目录）后重装 v0.0.7 探针；③ 若仅个别文件残留，删除 `Packages/com.dsh.bridge/Editor/*` 后重装。
- 验证：`bridge_targets` 状态 `ready`；`npm test` 全绿。
