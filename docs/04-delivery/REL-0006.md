# REL-0006｜DSH-Bridge v0.0.9 发布记录（AUD-CODE-001 修复）

## 变更集合

- 审计修复：AUD-CODE-001 的 P0（1 项）、P1（12 项）、P2（约 35 项）全部修复或按明确取舍处理。
- 版本：两处 `package.json` = `0.0.9`；探针 `PROBE_VERSION` 25 → **26**（旧探针需重装）。
- 变更内容：
  - 安全：MiniJson 深度/大小上限；探针侧 13 项危险能力闸门；反射面元编程类型/返回值拦截；拒绝写探针自身源码；scene/build/jobId 路径校验；通道 0700/0600。
  - 协议：NaN/Infinity→null；outbox 失败保留 in-flight；事件序号加锁与跨域取 max；args 类型校验；请求/instance/job 大小上限；CodeOfExtended 错误码映射。
  - 作业：PlayMode 测试显式拒绝；构建失败分流；bake.lighting 归属校验；test 作业超时/错误回调/取消；package 对账；jobId 校验；持久化原子；记录上限；navmesh 作业化。
  - 能力语义：validate 仅 .cs / defines 来自编译管线；sequence 预算；asset.create overwrite；scene_dirty；apply_edits 编码保留；截图 ScreenCapture/fallback/清理；input.send delivered。
  - 安装器：入口文件最后写、清理清单外旧文件、卸载以目录存在判断；测试硬编码 files 数改为模板驱动。
- 兼容性：
  - 探针版本变化触发 `probeOutdated`，需 `bridge_install` 重装。
  - 行为收紧：`validate` 仅 .cs；`asset.create` 已存在需 overwrite；`sequence` 上限 200/5000/10s；危险能力在探针侧也要求授权（DSH 侧默认拒绝语义不变）。
- 数据/架构迁移：无数据迁移；旧作业文件可读（损坏文件报 job_corrupted）。

## 验证与风险

- 离线：`npm test` 全绿（含新增审计回归断言与语义用例）；`npm run check:probe` 通过；`check:docs` 通过；`openspec validate --specs` 通过。
- 真机（团结 2022.3.62t7）：`verify:live` 与 `verify:tools` 全通过；重点抽查通道权限 0700/0600、未授权危险能力拒绝、jobId 拒绝、validate(.cs)、NaN 响应、asset.create overwrite。
- 已知残余风险（文档记录）：动态程序集不可卸载（进程内编译固有）；截图超大尺寸内存峰值；File.Replace 在部分 Mono 版本的原子性；PlayMode 测试不支持（显式拒绝）；串流/系统对话框需原生层。

## 回滚

- 触发条件：v0.0.9 在目标工程出现兼容性问题（例如依赖旧 `validate` .txt 行为或旧 sequence 参数）。
- 步骤：回退插件到 v0.0.8；目标工程 `bridge_uninstall` 后重装；旧探针行为恢复到 v0.0.8。
- 验证：`bridge_targets` 状态 ready；`npm test` 全绿。
