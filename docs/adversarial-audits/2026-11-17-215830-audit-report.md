## Findings 详情

### [P2] AA-CLI-102 — 布尔 flag 集合不得包含需要值的参数

- **位置**：`scripts/bridge-cli.mjs` → `BOOLEAN_FLAGS`
- **触发条件**：`bridge-cli install <path> --wait 30000`
- **错误行为**：`wait` 被当作布尔 flag，`30000` 落进 positional；`Number(flags.wait ?? 120000)` 取到 `true` → `Number(true)=NaN`
  → `readyTimeoutMs` 变成 `NaN`，等待逻辑退化（静默回落到无效值），安装看似成功但可能提前放弃等待编译。
- **影响**：`--wait` 参数完全失效，且没有任何报错；与上一轮 `--yes` 吞路径是同一类错误的两个方向。
- **修复**：`BOOLEAN_FLAGS` 只保留真正无值的 `yes/json/help/dry-run`；`wait/timeout/roots/deny/allow-dangerous` 均需值。
- **验证**：`inspect --json <path>` 仍正确解析；代码审查确认 `--wait` 恢复为带值参数。
